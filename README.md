# Perpetua LIS — Homepage Concept

**Initial design direction — for discussion.** Prepared by Muhammad Ayaan.

Responsive homepage with About, capability tabs, FAQs and five-second looping workflow illustrations.

## Preview

Open `index.html` in a modern browser, or run:

```sh
node server.cjs
```

Then visit http://127.0.0.1:4173/ . No dependencies need installing. Google Fonts and the existing public product video require internet access.

## Review status

Design and copy are proposed, awaiting client review. Illustrations are not actual product interface screenshots. Walkthrough buttons demonstrate an interaction only; booking, CRM, chatbot, checkout, subscriptions and LIS provisioning are not connected.

The existing Perpetua Foundry logo and public demonstration material are retained as reference assets for this concept. No rights to third-party brand assets are granted by this repository.

The local server serves an explicit list of public assets. Internal project notes, audits and client communications are excluded. Production hosting, accessibility/performance acceptance and integrations require separate configuration and testing. No hiring, price or implementation approval is implied.
