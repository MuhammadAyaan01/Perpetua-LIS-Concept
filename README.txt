Perpetua Foundry / Perpetua LIS — Homepage concept
Initial design direction — for discussion.
Prepared by Muhammad Ayaan.

Preview
Open index.html in a modern browser for a quick preview.
For the local server preview, install Node.js from its official website if needed,
open a terminal in this folder and run:
  node server.cjs
Then open http://127.0.0.1:4173/
If that port is already in use, stop the other local preview first.

Included
Responsive homepage with About, capability tabs, FAQs and five-second looping
hero/capability illustrations. Required styles, scripts and optimised images
are included. No package installation or framework build is needed.

Review status
This is one proposed design direction, not a production website.
Illustrations are not actual product interface screenshots.
Walkthrough buttons demonstrate the interaction only; booking, CRM, chatbot,
payments, subscriptions and LIS onboarding are not connected.
External company links lead to the existing Perpetua Foundry website.
Google Fonts and the existing public product video require internet access.
Current/planned product availability and all proposed copy need client approval.
The concept intentionally carries noindex instructions.

The included loopback-only server serves only the listed public files.
Production hosting, accessibility/performance acceptance and integrations
require separate configuration, agreed scope and testing before launch.
